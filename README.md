# **My First Website 🌐**

This project is my  **first personal website** , built as part of **The Complete Full Stack Web Development Bootcamp** on Udemy. It serves as a portfolio to introduce myself, showcase my skills, and provide a way for people to connect with me.

## **About the Project** ✨

This website is a simple yet stylish personal site that includes:

* A clean and modern **UI/UX** design.
* Sections introducing  **who I am** ,  **my passions** , and  **what I do** .
* A **contact section** where visitors can reach out to me.
* Responsive design to ensure it looks great on different screen sizes.

## **Technologies Used** 🛠

* **HTML** for structure
* **CSS** for styling (including gradients, flexbox, and animations)
* **JavaScript** (optional, if you added interactivity)

## **What I Learned** 📚

* Structuring web pages with  **semantic HTML** .

* Enhancing user experience with  **animations and effects** .
